怎么用（4 步）

1. 从飞书复制

  1. 在飞书文档里 Ctrl + A 全选，Ctrl + C 复制。
  2. 回到这里，点左边的大框，Ctrl + V 粘贴 —— 右边会自动出现 Markdown。

2. 检查 Markdown

  • 工具靠「字号比正文大多少」判断几级标题，个别地方可能判错，直接在右边改（比如把 ## 改成 ###）。
  • 整行加粗、又不长的短句会自动认成小标题（飞书的三级标题常和正文一样大）；不想要就在粘贴结果里把那个勾去掉，会重新转一遍。

3. 开始排版

  • 点「开始排版」进入第二步，左边仍是 Markdown（改了右边实时更新），右边就是公众号排版。
  • 上方可以换模板（科技 / 科普 / 教程 / 认知 / 商业 / 历史 / 情感 / 文化 / 生活）；点「改样式」能点选改颜色 / 字体 / 引用块底色这些（不用看代码），里面还有 12 个现成颜色一键换。改过的项会标「已改」，点一下就能退回模板默认。真想手写 CSS 的话，弹层底部有「高级：直接写 CSS」。

4. 复制进公众号

  1. 点「复制到公众号」，然后去 mp.weixin.qq.com 的编辑器里 Ctrl + V 粘贴。
  2. 粘完先点「预览」发到手机上确认一眼，再保存。
  3. 万一粘过去发现标题变成了普通段落（个别版本的公众号编辑器会把 h1 标签吃掉），回到「设置 → 标题兼容」切到「用 section」，重新点一次「复制到公众号」。
两个必须知道的限制（公众号本身的规定，不是工具的 bug）：
① 外链不能跳：正文里的 https://… 粘过去是纯文字，需要的话在「设置」里勾选「外链列到文末」。
② 飞书图片是链接、不是文件：多数情况下公众号能直接抓到（实测可行），不用管；如果某张图在公众号里裂了，把它另存到本地，点「补图」按顺序换成本地图片（会内嵌进排版，粘过去一定能显示）。
这个工具不联网、不上传：断网也能用，内容只在你电脑上。
