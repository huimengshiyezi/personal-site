# 个人站（personal-site）

> 葉子的个人网站：主页 + 工具聚合页。线上地址 <https://ai-huimengshiyezi.top>

## 仓库里有什么

| 目录 | 作用 |
|---|---|
| `个人站/` | **源码**（唯一源）：`index.html`（单文件，含全部样式与脚本）＋ `tools/` 4 个工具页 ＋ `images/` 获奖证书与公众号二维码 |
| `_deploy/` | **部署产物**：与 `个人站/` 同名文件逐字节一致的副本，托管平台发布的就是这一份 |

站点是**纯静态、零依赖、断网可用**：不引外部字体 / CDN / 统计脚本。

## 本地预览

双击 `个人站/index.html` 即可（无构建步骤）。

## 部署

改完源文件后的完整链路（构建脚本不在本仓库内）：

```
改 个人站/ 里的文件（工具类先跑各自的构建脚本）
   ↓
node 3-开发脚本/prep-deploy.mjs --apply      # 生成 _deploy/
   ↓
git commit && git push                       # 推送后平台自动部署
```

- **`_deploy/` 必须一起提交** —— 它是部署源，平台发布的就是它。
- 平台侧构建设置：**编译命令留空**、**输出目录填 `_deploy`**（纯静态，不需要构建）。
