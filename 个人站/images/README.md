## 二、公众号二维码（待补充）

```
images/qrcode.jpg
```

在公众号后台 →「设置与开发」→「公众号设置」→ 下载**二维码**（或直接截图裁剪）。
命名成 `qrcode.jpg` 丢进来，首页左栏点「关注公众号」就会展开显示。

**建议**：正方形、500×500 左右即可，白底不要裁太紧（微信识别需要留边距）。

---

## 通用规则

| 事项 | 说明 |
|---|---|
| **文件名** | 一律小写英文 + 连字符，**不要中文名**（部分环境乱码） |
| **格式** | `.jpg` 最通用；用 `.png` / `.webp` 要把 `index.html` 里的后缀一起改 |
| **大小** | 每张压到 **300 KB 以内**（用站内「图片压缩」工具压一下） |
| **加减作品** | 复制 `index.html` 里一整行 `<div class="thumb">…</div>`，改文件名即可 |
