「画面原封不动时」这一列要说清两件事：① 只有目标格式 = 原格式（PNG→PNG / JPG→JPG / WebP→WebP）且你勾了「剥掉元数据」时，才是字节级剥离、一个像素都不重编码；② 只要你把格式换成别的（比如 JPG → PNG），就必须重编码一次 —— 那时 PNG 只是不再新增损失，救不回已丢的细节。
裁剪、90° / 180° / 270° 旋转、翻转都是像素级搬运、不重采样 → 配 PNG 输出不新增损失； 改尺寸（重采样）、任意角度旋转、加水印（重绘像素）这一环是有损的。 而如果原图本来就是 JPG / WebP，它在被压缩那一刻就已经损失过，后面无论做什么都救不回来（只是「不再新增」而已）。

JPG 会丢掉 APPn / 注释段，PNG 会丢掉 tEXt / zTXt / iTXt / tIME / eXIf，WebP 会丢掉 EXIF / XMP 块。这个动作本身不损失画质；注意丢掉的也包括拍摄时间、相机型号、GPS 定位这些信息。

目标体积 勾上左边的开关才生效

开启后会自动来回试画质（画质不够就继续降），尽量压到不超过这个体积。万一实在压不到（比如图太复杂或者目标太小），会保留压出来的最小结果，并明确告诉你「已压到 X KB，未能达到目标」，不会偷偷给你一个不符合预期的文件。

背景色白色

JPG 不支持透明。不勾这个开关时，透明处默认填白色；勾上就能自己选颜色（例如电商图想要浅灰底）。
